# سحابة (Sahaba)
- One-line positioning: منصة لحماية ومشاركة الأفكار الإبداعية والروايات بين المستخدمين
- Target users: كتّاب، مبدعون، أصحاب أفكار المشاريع، يريدون حماية أفكارهم ومشاركتها
- Core features:
  1. تسجيل/تسجيل دخول بالبريد الإلكتروني مع استكمال الملف الشخصي الإجباري
  2. بوابة الأفكار: كتابة وحفظ الأفكار مع خيار مجاني أو بيع
  3. بوابة الروايات والقصص: كتابة روايات كاملة مع خيار مجاني أو بيع
  4. معاينة جزئية للمحتوى المدفوع قبل الشراء
  5. نظام حماية حقوق الملكية الفكرية مع تواريخ التوثيق
  6. إدارة المستخدمين: حذف المحتوى المسيء وتعليق الحسابات
- Important features (P1):
  1. نظام الشراء الافتراضي (بدون دفع حقيقي في النسخة الأولى)
  2. تصميم بشكل سحابة بيضاء ناعمة وجميلة
- Device strategy: adaptive
- Design style: سحابة بيضاء، ألوان هادئة زرقاء وبيضاء، تصميم عصري نظيف
- Technical constraints: Drizzle ORM + PostgreSQL, Next.js App Router
- Nova Agent: not needed
- Completed: قاعدة البيانات
- Current iteration: بناء التطبيق الكامل
